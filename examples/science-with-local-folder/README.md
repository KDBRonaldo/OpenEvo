# Science With Local Folder

This example documents the ordinary science workflow in OpenEvo Desktop:

1. Add and connect a remote workspace in Desktop.
2. Create a research project.
3. Choose a folder on the Mac as the project source.
4. Let Desktop snapshot and upload the selected files into the Daemon-managed
   project workspace.
5. Configure the task and textual evolution targets, then activate the project.
6. Start and monitor sessions from Desktop.

The user does not choose a remote workspace path, edit an experiment YAML file,
or operate OpenEvo on the server. Desktop owns transfer, integrity checks,
Daemon setup, and reconnection.
