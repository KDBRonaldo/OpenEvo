# Migration Notes

OpenEvo is a breaking pre-release migration to an OpenEvo-only product model.
Old runtime data is not required to remain compatible.

Public runtime identity is:

```text
OPENEVO_*
/openevo/session
openevo.session_completed
.openevo/evolution/
```

Historical design documents are kept under `docs/maintainer/development-history/`
for maintainers. They are not current product docs.
