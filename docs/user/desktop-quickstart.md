# OpenEvo Desktop Quickstart

1. Install OpenEvo Desktop from the macOS `.dmg`.
2. Launch the app and create a project.
3. Enter the remote GPU server host, port, user, and SSH auth reference.
4. Configure proxy, pip index, and Hugging Face mirror settings if the server
   needs them.
5. Run remote doctor/bootstrap from Desktop.
6. Start the remote OpenEvo Core Backend.
7. Choose Codex subscription transcript mode or self-deployed mode.
8. Start the science run and monitor the timeline, logs, and artifacts.

Desktop should show setup-required or typed error states until a real sidecar
and remote Core Backend are reachable.
